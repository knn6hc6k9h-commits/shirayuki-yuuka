# 白雪ゆうか 単語の意味設定
#
# 「ゆうかに話しかける」で入力された文章を、意味ごとに分類する一覧です。
# [意味名] の下に、同じ意味として扱いたい単語・短い文章を1行ずつ書きます。
# 行を追加すると判定語を追加、行を削除すると判定語を削除できます。
# 上から順に調べ、最初に一致した意味が使われます。
#
# 意味名は対応するイベントIDになります。
# 例: [thank] -> EVENT|Thank|...
#     [praise] -> EVENT|Praise|...
# 新しい意味を作る場合は dialogue.txt または user_events.txt に
# 対応する EVENT を追加してください。
#
# [apology] は特別扱いです。
# ここに登録された言葉は既存の Apology 判定へ渡され、
# 秘密のカウントを減らす既存の動作もそのまま働きます。
#
# [thank] は、EVENT|Thank|... があればそれを優先します。
# Thankイベントがない場合は既存の「ありがとう」返答を使います。
#
# このファイルはネットワーク更新では上書きされません。
