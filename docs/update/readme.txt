白雪ゆうか ゴースト Ver.1.2 - Dialogue / Talk Editable

主な変更:
- ユーザー提供の dialogue.txt を標準台詞として採用
- dialogue.txt に REPLY 書式を追加し、ユーザーから任意の言葉を入力して話しかけられる機能を追加
- メインメニューに「ゆうかに話しかける」を追加
- アンインストール操作時の VanishSelecting / VanishCancel / VanishSelected 台詞を外部編集可能に追加
- スカート上方向ホイールは初期設定で短時間に3段階ぶん必要にし、誤反応しにくく調整
- user_config.txt からスカート上方向の感度を変更可能

詳しくは DIALOGUE_EDIT_GUIDE.txt を参照してください。

Ver.1.3: 太もも当たり判定を追加。クリック=触る、カーソル移動=なでなで。dialogue.txtで台詞編集可能。


Ver.1.4 compact update:
- 全キャラクターサーフェスを約50%に縮小しました。
- 当たり判定も同じ比率に縮小しています。
- 頭・目・口・胸元・スカート・太ももの反応は維持されます。

Ver.1.4.1 fix:
- 通常のSkirt領域反応でも、反応後に約3秒のクールダウンが必ず入るよう修正。
- dialogue.txt の OnYuukaSkirtWheelUp が存在する場合でもクールダウンが抜けないよう、設定順序を修正。
- レア反応側のクールダウン仕様はそのまま維持。


Ver.1.5 update:
- 胸元クリックとスカート上方向反応をセクハラカウントとして内部保存。
- セクハラカウントが一定以上で、不機嫌寄りの RandomTalkGrumpy に切り替え。
- 頭をなでる反応1回につきセクハラカウントを1減少。
- なかよし度80以上ではセクハラカウントが増加しない仕様。
- 閾値と無効化なかよし度は user_config.txt から変更可能。


Ver.1.6 機嫌システム
- 0～20: 通常 / 21～50: 不機嫌 / 51以上: 怒り
- 頭のなでなで反応1回につきセクハラカウント -1
- 話しかけ入力で謝罪語を含むと -5
- なかよし度80以上では新規加算なし
- EVENT|IDGrumpy|... / EVENT|IDAngry|... を追加すれば各イベントを機嫌別にできます。
- 機嫌別台詞がなければ通常版へ自動フォールバックします。


Ver.1.6 update:
- 機嫌を通常 / 不機嫌 / 怒りの3段階に拡張。
- セクハラカウント21～50で不機嫌、51以上で怒り。
- 頭のなでなで反応で-1、話しかけて謝ると-5。
- なかよし度80以上では新しいカウントは増えません。

Ver.1.7 update:
- 制服の胸元/襟まわり(Bust)はシングルクリックでは反応せず、ダブルクリック時のみ反応します。
- メインメニュー→設定から「セクハラカウントの増加」をON/OFFできます。
- OFF中も現在値は保持され、頭なで(-1)・謝罪(-5)による減少は継続します。
- ON/OFF設定は再起動後も保存されます。
