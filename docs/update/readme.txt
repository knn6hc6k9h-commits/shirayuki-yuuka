白雪ゆうか ゴースト Ver.1.0

現在の主な機能:
- ランダムトーク、呼びかけへの返答、起動時・復帰時などの各種会話
- 表情差分と、頭・目・口・胸元・スカート・太ももなどのリアクション
- なかよし度、機嫌、セクハラカウントなどの状態変化
- 名前・誕生日などの設定保存
- メニューからランダムトーク頻度などを変更可能
- ユーザー設定・追加イベントのカスタマイズに対応
- ネットワーク更新に対応

詳しいカスタマイズ方法は DIALOGUE_EDIT_GUIDE.txt / CUSTOMIZE_README.txt を参照してください。
